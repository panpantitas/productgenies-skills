# nielsen-heuristic-audit

Nielsen เคยใช้หลักการ 10 ข้อนี้เป็นเกณฑ์ตรวจการบ้านนักศึกษา ตอนนี้เราให้ AI ใช้เกณฑ์ชุดเดียวกันตรวจ UI ให้ได้

## สิ่งที่ได้

- ตารางปัญหาที่พบ เรียงตามความรุนแรง พร้อมระบุว่าละเมิดข้อไหน
- ข้อเสนอแนะที่ทำตามได้จริง
- สิ่งที่ทำได้ดีอยู่แล้ว
- สกอร์การ์ดรายข้อ และข้อจำกัดของการตรวจ

## วิธีใช้

1. ดาวน์โหลดไฟล์ [`SKILL.md`](./SKILL.md)
2. เลือกอย่างใดอย่างหนึ่ง
   - **ถ้าใช้ Claude ที่รองรับ Skills:** เพิ่มเป็น skill ตามขั้นตอนของแอป
   - **ถ้าไม่ได้ใช้ skills:** เปิดไฟล์ แล้วคัดลอกเนื้อหาไปวางใน chat จากนั้นแนบภาพหน้าจอหรือบอกว่าอยากให้ตรวจ flow ไหน
3. บอกบริบทสั้นๆ: ใครคือผู้ใช้ ผู้ใช้ทำอะไรในหน้านี้ และเป็นมือถือหรือเว็บ

## ข้อควรรู้

- เป็นการตรวจรอบแรก ช่วยหาปัญหาที่เห็นได้ชัดก่อนถึงมือผู้ใช้ ไม่ได้แทนการทดสอบกับผู้ใช้จริง
- ผู้ตรวจคนเดียวมักหาปัญหาได้เพียงส่วนหนึ่ง ถ้าเป็น flow สำคัญ ควรมีคนตรวจเพิ่มหรือทดสอบกับผู้ใช้
- ภาพนิ่งไม่แสดง animation เวลาตอบสนอง หรือสถานะ error ที่ไม่ได้แคปมา AI จะบอกว่าส่วนไหนตัดสินไม่ได้

## เครดิต

หลักการ 10 ข้อโดย Jakob Nielsen (1994) ดูต้นฉบับได้ที่ [Nielsen Norman Group](https://www.nngroup.com/articles/ten-usability-heuristics/) คำอธิบายใน skill เป็นการเรียบเรียงใหม่ ไม่ได้คัดลอกจากต้นฉบับ
