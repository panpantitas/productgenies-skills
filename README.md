# Product Genies Skills

คลัง skill ฟรีจาก [Product Genies](https://productgenies.com) สำหรับคนทำงาน product และ UX ที่อยากให้ AI ช่วยงานได้ตรงจุดขึ้น

## Skills ในคลังนี้

| Skill | ทำอะไร |
|---|---|
| [`nielsen-heuristic-audit`](./nielsen-heuristic-audit) | ให้ AI ตรวจ UI ตามหลัก Nielsen's 10 Usability Heuristics พร้อมให้คะแนนความรุนแรง 0–4 และสรุปเป็นรายงาน |

วิธีใช้ของแต่ละ skill อยู่ใน README ในโฟลเดอร์ของ skill นั้น
